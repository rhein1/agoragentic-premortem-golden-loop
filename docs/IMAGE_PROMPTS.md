# Image Generation Prompts

Use these prompts for GitHub social preview, README hero, and documentation images. Keep all text out of the image unless the tool renders typography reliably; add labels in the README instead.

## GitHub Social Preview

```text
Create a clean cinematic product image for an open-source developer tool called "Agoragentic Premortem Golden Loop Agent". Scene: a dark navy engineering workspace with a terminal window, local JSON receipts, a premortem report, and a clear loop of three illuminated checkpoints: Premortem, Self-Test, Self-Heal. Visual mood: precise, trustworthy, local-first, OSS, no cloud upload. Include subtle green and amber accents for pass/warn states, not a generic purple gradient. No people, no robots, no mascots, no coins, no crypto hype. Composition should work as a GitHub social card at 1280x640, with negative space on the left for overlay text added later. High contrast, sharp UI details, modern but restrained.
```

## README Hero Image

```text
Create a wide README hero image for a free local-first AI agent safety CLI. Show a laptop running a terminal command, a generated dark-mode premortem report, and a local folder of receipts under ".agoragentic/premortem-golden-loop/". The visual metaphor should be a closed local circuit: files enter, reports and safe fixes come out, with a visible boundary line showing "nothing leaves the machine" through imagery only, not text. Style: polished technical product render, dark background, clean typography-like UI panels without readable fake text, green check accents, amber warning accents, crisp realistic lighting. Avoid stock-photo feel, avoid humanoid robots, avoid blockchain imagery.
```

## Workflow Diagram Image

```text
Create an isometric technical workflow diagram for an OSS agent release safety loop. Five stations connected clockwise: Plan Premortem, Repo Audit, Golden Loop Receipt, Self-Heal Plan, Owner Review. The loop should sit inside a local machine boundary, with an optional dotted line leading to "public no-spend canaries" represented as a small external status beacon. No sensitive data leaves the local boundary. Use dark navy, slate, white, green, and amber. Clean SaaS infrastructure style, precise lines, readable shapes, no cartoon characters, no cute mascots, no coins, no dramatic explosions.
```

## Icon Prompt

```text
Create a simple square app icon for "Agoragentic Premortem Golden Loop Agent": a circular loop surrounding a document with a checkmark and small warning triangle. Style: flat vector-like but rendered as a polished bitmap, dark navy background, green and amber accents, high contrast, recognizable at small sizes. No letters, no faces, no robots, no coins.
```
